OpenTouchDesigner
=================

1. Drag OpenTouchDesigner.app to Applications.

2. The first launch will be refused: "Apple could not verify ... free of
   malware". This build is signed with a project certificate, not an Apple
   Developer ID, and it is not notarised. Nothing is wrong with the app;
   Gatekeeper has no Apple signature to trust.

   To open it anyway, either:

     - Right-click the app > Open, then Open again in the dialog, or
     - System Settings > Privacy & Security > "Open Anyway", or
     - In a terminal:
           xattr -dr com.apple.quarantine /Applications/OpenTouchDesigner.app

   You only have to do this once.

   If you would rather not run a binary Apple has not notarised — a
   reasonable position — build from source instead. It is one command and
   needs nothing but Rust:

       cargo run -p otd-app

3. Python is bundled inside the app (Contents/Resources/python/). You do not
   need Homebrew Python on the show machine.

4. Microphone and camera prompts appear the first time a patch uses an Audio
   Device In CHOP or a Video Device In TOP. Both are optional. OSC from
   another machine needs Local Network access: allow it the first time the
   app is double-clicked. Builds signed with the same certificate keep that
   grant.

5. Movies need ffmpeg:  brew install ffmpeg
   It is found on the PATH or in the usual install directories, so it works
   whether you launch from Finder or a shell.
   Still images (PNG, JPEG, WebP) work without it.

Docs, source and issues: https://github.com/Ar9av/opentouchdesigner
